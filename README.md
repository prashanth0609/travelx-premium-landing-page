# 🌍 TravelX – Premium Travel Landing Page

TravelX is a modern and premium travel website landing page built using pure HTML and CSS.  
This project is designed for beginners who want to improve their front-end development skills while creating a luxury-level responsive UI design.

---

## ✨ Features

- Premium Modern UI
- Fully Responsive Design
- Smooth Hover Effects
- Luxury Hero Section
- Destination Cards
- Glassmorphism Navbar
- Gradient Buttons
- Mobile Friendly Layout
- Clean and Organized Code
- Attractive Color Palette

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries
